            Built-in Data Structures
1. List
2. Tuple
3. Dictionary
4. Set

List - A list is a built in data type in python that stores multiple items in a single variable.
It stores Homogeneous and heterogeneous type of data

fetaures:
1. Ordered - Elements maintain their position in the list
2. Mutable - Which means we can modify its elements after creating it
3. Allows duplicates
4. Supports indexing
5. It supports nested List
6. Allows different data types



Tuple - A tuple is a built in Python data type used to store multiple items in a single variable.

fetaures:
1. Ordered - Elements maintain their positions
2. Immutable - Elements cannot be modified after creation.
3. Allows duplicates
4. Allows different data types
5. Indexing
6. It supports nested list


Dictionary - A Dictionary is a built in python data type that stores data in the form of key-value pairs.

fetaures:
1. Key-value pairs
2. Mutable
3. Ordered
4. Unique keys
5. Different data types
6. Values can be duplicated

Set - A set is a collection of Unique elements. It does not allow duplicate values

fetaures:
1. Sets are mutable
2. Sets do not allow duplicate values
3. Sets are unordered
4. Sets do not support indexing
5. Sets can contain different data types
